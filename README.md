## 📊 Combinatorial Mathematics

The frequencies come from the combinatorics rather than from simulations. There are C(52,7) = 133,784,560 seven-card sets; a royal flush appears in 4,324 of them, which is 0.0032%, or 1 in 30,940 — the widely quoted 1 in 650,000 is the five-card-draw figure. 

The starting grid covers all 169 hand types (13 pairs, 78 suited, 78 offsuit, drawn from 1,326 two-card combinations) and groups them into play, conditional and fold tiers as a starting reference for newer players, not a fixed answer for every position, stack depth or table.
